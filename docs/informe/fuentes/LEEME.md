# Fuentes

La consigna pide **Calibri 11**. Calibri es una fuente propietaria de Microsoft y no
está disponible en todos los equipos, de modo que el informe se compone con
**Carlito**, que es métricamente compatible con Calibri: mismo ancho de glifo,
mismo interlineado y un diseño prácticamente idéntico. El resultado impreso es
equivalente.

Carlito es software libre (SIL Open Font License 1.1) y se obtuvo de Google Fonts.
